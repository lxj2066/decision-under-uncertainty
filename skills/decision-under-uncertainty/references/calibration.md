# 校准与复盘（calibration）

概率不是用来“显得专业”的，是用来被结果检验的。

## 1. 决策日志

每次决策前写一条，**在做之前**，不是事后补：

```json
{
  "id": "D0001",
  "date": "2026-10-26",
  "decision": "是否投入 3 个月做 X",
  "p": 0.35,
  "horizon_days": 90,
  "stake": "30000 元 + 3 个月",
  "criteria": {
    "success": "付费用户 ≥100",
    "stop": "预算花到 30% 且无留存"
  },
  "key_evidence": ["E1 灰度转化 8%", "E2 同类项目基准率 25%"],
  "predicted_outcome": "大概率不达标，但小规模可行"
}
```

结果出来后追加 `outcome: 0|1`，不要改前面的 p。

## 2. Brier 分数

`BS = mean((p − outcome)^2)`

| 分数 | 含义 |
|---|---|
| 0.25 | 等于一直猜 50% |
| 0.18 | 略好于抛硬币 |
| ≤0.10 | 校准不错 |
| >0.25 | 比一直猜 50% 还差（系统性过度自信或反向） |

样本 <20 条时，Brier 波动很大，只看趋势，别下结论。

## 3. 分桶校准

把预测分成 50–60%、60–70%、70–80% 等桶，看每桶的实际成功率。

- 预测 70% 的事，实际 70% 左右 → 校准良好
- 预测 70%，实际 50% → 系统性过度自信
- 预测 70%，实际 90% → 过度保守

## 4. 复盘节奏

| 节点 | 动作 |
|---|---|
| 决策当天 | 写日志、定阈值 |
| 30 天 | 看是否触发止损；不改原概率，只记录新证据 |
| 结果发生 | 打分，写「当时哪条证据最有信息量」 |
| 每季度 | 看 Brier 趋势与分桶校准 |

## 5. 复盘的正确姿势

**要问的**：
- 当时哪条证据是高估的？哪条被忽略了？
- 是先验错了，还是 LR 错了？
- 如果重来，哪个环节会改？

**不要问的**：
- 「结果不好是不是说明决策错了？」——好决策也可能坏结果。
- 「早知道就……」——后见之明偏差。

## 6. 用工具记账

```bash
# 追加一条
python -I scripts/decision_calc.py journal add.json
# 回填结果
python -I scripts/decision_calc.py journal eval.json
# 看总览
python -I scripts/decision_calc.py journal list.json
```

`journal` 子命令会写 `decision_journal.json`，包含 Brier 与分桶校准。

## 7. 什么时候该提高置信度

只有三种情况：

1. 新增了**独立**证据（不是同源转载）
2. 做了真实实验，拿到了自己的数据
3. 参考类找到了更贴近的样本

“想得更久了”“又看了几篇文章”不算。
