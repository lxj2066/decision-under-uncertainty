# 方法论（methodology）

本文件是计算器的公式说明书。**先理解假设，再信数字。**

## 1. 先验与基准率（outside view）

原则：先看「同类事情的历史成功率」，再看「这次有什么不同」。

- 参考类要具体：不是「创业」，而是「2020–2025 年、中国、单人、内容类、启动成本 <5 万的项目」。
- 参考类越宽，先验越不可靠；至少给出处与样本量。
- 没有数据时：写 `UNKNOWN`，先验给区间（如 0.2–0.6），并在敏感性分析里展示区间影响。

**禁止**：用「行业平均」「通常来说」生成一个点估计。

## 2. 贝叶斯更新

先验 p → 先验几率 `O = p/(1-p)`。

每条独立证据有似然比 LR：`LR = P(证据|成立) / P(证据|不成立)`。

后验几率：`O_post = O_prior × Π LR_i`。

后验概率：`p_post = O_post / (1 + O_post)`。

### 2.1 三重保护（本方法的核心）

| 保护 | 规则 | 原因 |
|---|---|---|
| **截断** | LR 限制在 `[0.1, 10]`（可配） | 单条「铁证」不该把概率推到 0.99/0.01 |
| **可靠性收缩** | `LR_eff = LR ^ reliability`，reliability ∈ [0,1] | 二手信息、匿名爆料应弱于一手数据 |
| **相关去重** | 同一簇只取一个合并值（max / geomean / sqrt） | 十条同源报道不是十条独立证据 |

> 默认 `sqrt`：`LR_cluster = 1 + (geomean(LR) - 1) / sqrt(n)`。它比直接相乘保守，比只取一条宽松。

### 2.2 敏感性

- 先验区间：`[p/2, 2p]`（可自定义）→ 后验区间。
- 每条 LR ±20% → 后验上下界。
- 结论：如果后验在两种合理假设下跨过决策阈值，说明**证据还不够**，不是「差不多能做」。

## 3. 期望值与效用

单方案：

```
p_eff = p × q                 # q = 计划按预期执行的概率
EV    = p_eff × gain − (1 − p_eff) × loss − cost
max_loss = loss + cost
```

盈亏平衡成功率：`p* = (loss + cost) / (gain + loss)`。

若 `p_eff < p*`，EV 为负——不管故事多好听。

### 3.1 风险厌恶

指数效用：`U(x) = (1 − e^(−a x)) / a`（a=0 退化为风险中性）。

`EU = p_eff × U(gain − cost) + (1 − p_eff) × U(−loss − cost)`。

排序用 EU 而不是 EV，会压低「小概率大赢」的吸引力。

### 3.2 破产

若 `max_loss ≥ capital`，判破产风险。**破产的期望值没有意义**——先活下来。

## 4. Kelly 仓位

净赔率 `b = gain / loss`，最优比例 `f* = (p·b − (1−p)) / b`。

- 全 Kelly 波动极大；实盘建议 ≤ 半 Kelly，常用四分之一。
- 负期望时 `f* ≤ 0`，不应下注。
- 本工具用 `fraction_cap`（默认 0.25）截断。

## 5. 重复尝试

一次尝试的定义必须写清楚（一次投放？一次投递？一轮实验？）。

独立假设：`P(n 次内成功) = 1 − (1−p)^n`，期望次数 `1/p`。

相关性：用混合近似

```
P_corr(n) = ρ·p + (1−ρ)·[1 − (1−p)^n]
```

ρ = 尝试之间共享结果的比例（同选题、同渠道、同团队 → ρ 高）。

> 这是近似，不是精确模型；结论要写明「ρ 为估计值」。

预算约束：`n_max = floor(budget / cost_per_attempt)`，据此算预算内成功率与期望成本。

## 6. 故障树与卡点

- 串联：`R = Π r_i`
- 并联（冗余）：`R = 1 − Π (1 − r_i)`

**关键度用留一法**：

```
Δ_perfect = R(把 i 设为 1) − R
Δ_failed  = R(把 i 设为 0) − R
```

不要用「各环节 Δp 相加」——那假设了独立且可加，实际会高估卡点贡献。

单点故障：`R(该环节失效) < 0.5`（阈值可调）。

## 7. 多准则决策（MCDA）

1. 明确准则与权重，权重和 = 1。
2. 原始分归一化到 0–100。
3. 成本型准则（风险、成本、时间）取反：`score = 100 − normalized`。
4. 加权和排序。

**权重必须在看结果前定**；否则就是给结论找理由。

## 8. 蒙特卡洛

输入用分布（triangular / normal / lognormal / uniform），跑 N 次，输出 EV 的 p5/p50/p95 与 `P(EV>0)`。

固定 seed，保证可复现。分布本身是估计——结论要写这一点。

## 9. 证据分级

| 级别 | 例子 | 对 LR 的处理 |
|---|---|---|
| T1 | 自己的实测数据、随机对照试验、审计报告 | reliability 0.9–1.0 |
| T2 | 同行评审研究、官方统计 | 0.7–0.9 |
| T3 | 行业报告、多个独立案例 | 0.5–0.7 |
| T4 | 单条新闻、朋友经验、网帖 | 0.2–0.4 |

相关证据（同源、同作者、同数据）必须归入同一簇。

## 10. 校准

Brier 分数：`BS = mean((p_i − o_i)^2)`，越低越好。

- 0.25 ≈ 一直猜 50%
- 0.10 以下算不错
- 分桶校准：预测 70% 的那批事，实际发生率应接近 70%

## 11. 明确边界

- 本方法不生产事实，只组织不确定性。
- 输入是估计，输出就只是「有条件结论」。
- 不适用于：价值观选择、纯运气事件、无法定义成功标准的问题。
